1. 概述

欢迎使用"绿苑小助手"Chrome 浏览器扩展（以下简称"本扩展"）。我们致力于保护您的隐私和个人信息安全。本隐私权政策说明了我们如何收集、使用、存储和保护您的信息。

请仔细阅读本政策。使用本扩展即表示您同意本隐私权政策的条款。如果您不同意本政策，请停止使用本扩展。

2. 我们收集的信息

2.1 用户账户信息

  • 用户名和密码：用于用户身份验证和账户登录
  • 访问令牌：用于维持用户会话和授权 API 请求

2.2 浏览活动信息

  • 当前标签页 URL：用于检测用户正在浏览的电商平台
  • 商品页面信息：包括商品 ID、商品名称等基本信息

2.3 功能设置信息

  • 扩展启用/禁用状态：记录用户是否启用本扩展
  • 用户偏好设置：如语言、显示选项等

2.4 商品数据

  • 销量历史数据：从后端 API 获取的商品销量信息
  • 数据分析结果：基于商品数据生成的分析图表和统计信息
重要说明：本扩展不会收集您的个人身份信息（如真实姓名、电子邮件地址、电话号码等），除非您主动提供用于登录的用户名。

3. 信息的使用方式

我们收集的信息仅用于以下目的：

  • 身份验证：验证您的身份并维持您的登录会话
  • 功能提供：在电商平台页面上显示商品销量历史和数据分析图表
  • 平台检测：识别您正在浏览的电商平台（Amazon、eBay、AliExpress、Ozon、Wildberries）
  • 数据获取：从后端服务器获取商品相关的销量数据
  • 用户体验改进：根据您的偏好设置优化扩展功能

我们不会：

  • 将您的信息出售给第三方
  • 用于广告投放或用户追踪
  • 与无关的第三方共享您的个人信息
  • 用于任何商业目的以外的用途

4. 信息的存储和安全

4.1 本地存储

以下信息存储在您的本地浏览器中（使用 Chrome Storage API）：

  • 用户登录凭证（用户名、访问令牌）
  • 功能启用/禁用状态
  • 用户偏好设置

这些数据仅存储在您的设备上，不会自动上传到云端。

4.2 服务器存储

当您使用本扩展时，以下信息可能被发送到我们的后端服务器：

  • 用户登录请求（用户名和加密的密码）
  • 商品数据查询请求（商品 ID）

4.3 安全措施

  • 密码加密：用户密码在发送前使用 MD5 加密算法进行加密
  • HTTPS 连接：与后端服务器的所有通信均使用 HTTPS 加密
  • 访问控制：只有授权的请求才能访问用户数据
  • 本地隔离：本地存储的数据与其他网站隔离
注意：虽然我们采取了安全措施，但互联网上不存在完全安全的传输方式。我们无法保证数据的绝对安全。

5. 第三方服务

5.1 后端 API 服务

本扩展连接到我们的后端 API 服务器以获取商品销量数据。当您使用本扩展时，以下信息会被发送到后端服务器：

  • 用户登录凭证（用于身份验证）
  • 商品 ID（用于查询销量数据）

5.2 电商平台

本扩展在以下电商平台上运行：

  • Amazon（多个地区）
  • eBay（多个地区）
  • AliExpress
  • Ozon
  • Wildberries

这些平台有各自的隐私政策。我们建议您查看这些平台的隐私政策以了解它们如何处理您的信息。

6. 用户权利

根据适用的隐私法律，您拥有以下权利：

  • 访问权：您有权访问我们存储的关于您的信息
  • 删除权：您可以随时卸载本扩展以删除本地存储的所有数据
  • 更正权：您可以更新您的账户信息
  • 撤销权：您可以撤销对本扩展的授权

6.1 如何删除您的数据

  1. 在 Chrome 浏览器中卸载本扩展
  2. 本地存储的所有数据将被自动删除
  3. 如需删除服务器上的账户数据，请联系我们

7. 政策变更

我们可能会不时更新本隐私权政策以反映法律变化或我们的实践变化。我们将通过在本页面上发布新版本来通知您任何重大变更。您继续使用本扩展即表示您接受更新后的政策。
